# Model catalog

Use **Practice model** on [TriView](https://relic-31.github.io/TriView/) to select any model. A selected family stays active after a correct answer; **Mixed practice** uses the full collection.

There are 49 families: the original 25, 16 worksheet reconstructions and eight additional designs. Proportions, orientation and missing lines vary.

## Worksheet numbering

A is the first supplied sheet (red line drawings); B is the second (dark red drawings). Numbering reads each row from left to right, then moves downward.

The screenshots have no usable dimensions and some fine details are blurred. These entries reconstruct each depicted form using its companion views; they are not exact dimensional copies.
